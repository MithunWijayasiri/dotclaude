# Text on the page

Every sentence gives the reader one fact they need. Based on ASD-STE100 (Simplified Technical English) principles.

- Start with the answer. No preamble ("Here is an overview"), no closing summary or "hope this helps". Page ends when the facts end.
- No process narration ("I read the file, then…"). Give result + evidence: `path:line`, command, number.
- Each fact once. A diagram or table shows it → don't repeat it in text.
- One sentence, one fact. One name per thing throughout.
- Steps as commands, one action each, condition first: "If the build fails, read the log."
- Unverified fact → say so and how to check it. Don't hide it behind "probably".
- List every item, or say where the full list is. No "etc.".
- Plain words: "use", not "utilize".

## Limits

- Sentences: steps ≤20 words, descriptions ≤25 words.
- Paragraphs: ≤6 sentences; more → list.
- Steps in active voice. Descriptions may use passive when the actor doesn't matter.
- Counter-examples shown on purpose → strikethrough or a table row marked `no`, so they read as wrong.
